### Hardware Implementation Summary

1. **[`MemcpyRoCC`](file:///home/ray/chipyard/generators/chipyard/src/main/scala/example/MemcpyRoCC.scala)**:
   - **Instruction Decode (`OpcodeSet.custom0`)**:
     - `funct = 0`: Latches `src` (`cmd.bits.rs1`) and `dst` (`cmd.bits.rs2`).
     - `funct = 1`: Latches `len` (`cmd.bits.rs1`) and starts the copy FSM if `len > 0` (immediately finishes if `len <= 0`).
   - **L1 D-Cache Interface (`io.mem` via `SimpleHellaCacheIF`)**:
     - Uses physical addressing (`phys = true.B`, `no_xcpt = true.B`) and keeps the D-Cache clock enabled (`keep_clock_enabled`) while active.
     - **Head/Tail Byte Engine (`s_head_load` / `s_head_wait` / `s_head_store`)**: Handles unaligned leading bytes until `dst` is 8-byte aligned (and any trailing `< 8` bytes after the bulk phase) using 8-byte aligned loads (`size = 3.U`, `M_XRD`) and 1-byte stores (`size = 0.U`, `M_XWR`) with replicated byte data (`Fill(8, head_byte_val)`), guaranteeing no out-of-bounds writes outside `dst[0..len)`.
     - **Aligned Bulk Engine (`s_bulk_load` / `s_bulk_wait` / `s_bulk_store`)**: Performs 8-byte aligned loads (`M_XRD`, `size = 3.U`) and 8-byte aligned stores (`M_XWR`, `size = 3.U`). When `src` and `dst` have different alignments (`shamt_bits != 0`), a 64-bit staging register (`prev_word`) and barrel shifter merge consecutive 64-bit source words into aligned 64-bit destination words without redundant memory reads.
     - **Completion & Synchronization (`s_wait_stores`)**: Tracks in-flight requests with distinct tags for loads (`tag = 0`) and stores (`tag = 1, 2`) within `SimpleHellaCacheIF`'s 3-entry replay queue, holding `io.busy` high until `store_inflight === 0.U` so Rocket's `fence` instruction waits until all stores have committed in the L1 D-Cache.
